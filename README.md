# Amazon Clone 🛒

A frontend Amazon clone built with **HTML, CSS, and JavaScript** while following the JavaScript course by **SuperSimpleDev**.

This project focuses on practicing JavaScript fundamentals and building an interactive e-commerce website from scratch.

## ✨ Features

* Product listing
* Add products to cart
* Update product quantities
* Remove products from cart
* Checkout page
* Order tracking
* Interactive shopping cart
* Dynamic product rendering
* Persistent cart data using Local Storage

## 🛠️ Technologies

* **HTML5** – Page structure
* **CSS3** – Styling and layout
* **JavaScript** – Functionality and interactivity
* **Git & GitHub** – Version control

The main goal of this project was to improve my JavaScript skills by building a real-world style e-commerce website.

It helped me understand how different parts of a website work together, including products, shopping cart functionality, checkout, and order tracking.
